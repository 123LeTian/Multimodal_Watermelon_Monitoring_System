# 大棚西瓜多模态生长状态评估模型需求规格表

## 1. 模型名称

大棚西瓜多模态生长状态评估模型

## 2. 模型目标

基于西瓜图片和图片拍摄前 24 小时内的环境时序数据，判断西瓜当前生长阶段、健康等级、成熟度等级，以及是否存在西瓜生长异常。

本阶段只确定模型需求规格，不进行模型训练。

## 3. 输入数据

一个训练样本由以下两部分组成：

| 输入项 | 说明 |
| --- | --- |
| 西瓜图片 | 拍摄当前植株、叶片、花、果实或整体长势的图像 |
| 环境时序数据 | 图片拍摄时间点之前 24 小时内采集的环境数据 |

环境字段固定为：

| 字段 | 含义 |
| --- | --- |
| 温度 | 大棚内空气温度 |
| 土壤湿度 | 大棚内土壤湿度 |
| 光照 | 大棚内光照强度 |
| pH | 土壤 pH |

传感器故障、数据缺失、明显异常值、时间戳无法对齐等问题不作为模型标签，统一放到数据清洗阶段处理。

## 4. 输出结果

模型采用多任务输出，固定输出 4 个结果：

| 输出字段 | 输出名称 | 任务类型 | 含义 |
| --- | --- | --- | --- |
| `growth_stage` | 生长阶段 | 6 类分类 | 判断西瓜当前处于哪个生长阶段 |
| `health_level` | 健康等级 | 4 类分类 | 判断植株、叶片、果实等整体健康程度 |
| `maturity_level` | 成熟度等级 | 4 类分类 | 判断果实成熟程度；早期无果实时标为未成熟 |
| `abnormal_alert` | 生长异常预警 | 2 类分类 | 判断是否存在西瓜生长异常 |

## 5. 标签类别

### 5.1 生长阶段类别

| 标签值 | 标签名称 | 标注含义 |
| --- | --- | --- |
| 0 | 发芽期 | 种子萌发、幼苗刚形成，植株体量较小 |
| 1 | 伸蔓期 | 藤蔓明显伸长，叶片数量增加，尚未进入主要结果阶段 |
| 2 | 开花期 | 出现花蕾或开花现象，重点表现为花器官发育 |
| 3 | 坐果期 | 授粉后幼果形成，果实开始稳定保留 |
| 4 | 膨大期 | 果实体积快速增大，是果实发育的主要增长阶段 |
| 5 | 成熟期 | 果实接近采收或已经达到成熟状态 |

### 5.2 健康等级类别

| 标签值 | 标签名称 | 标注含义 |
| --- | --- | --- |
| 0 | 正常 | 长势正常，叶片和果实无明显异常 |
| 1 | 轻微异常 | 出现轻微叶片异常、轻微长势弱、局部轻微病斑等，不明显影响整体生长 |
| 2 | 中度异常 | 异常较明显，例如长势明显偏弱、叶片黄化/萎蔫较多、果实发育不均等 |
| 3 | 严重异常 | 异常严重，例如大面积病害、明显枯萎、果实严重畸形或发育停滞 |

### 5.3 成熟度类别

| 标签值 | 标签名称 | 标注含义 |
| --- | --- | --- |
| 0 | 未成熟 | 无果实、幼果阶段，或果实明显未达到成熟标准 |
| 1 | 接近成熟 | 果实已基本长成，但仍未完全达到采收成熟状态 |
| 2 | 成熟 | 果实达到正常采收成熟状态 |
| 3 | 过熟 | 果实超过最佳成熟期，可能出现品质下降或成熟异常 |

### 5.4 生长异常预警类别

| 标签值 | 标签名称 | 标注含义 |
| --- | --- | --- |
| 0 | 无异常 | 未发现西瓜生长异常 |
| 1 | 有异常 | 存在长势弱、叶片异常、果实发育异常、疑似病害、成熟异常等西瓜生长异常 |

注意：异常预警只标注西瓜生长异常。传感器损坏、数据缺失、通信失败、设备离线等不属于该标签。

## 6. 模型结构

暂定模型结构为：

ResNet50 图像分支 + Transformer 环境时序分支 + 特征融合层 + 多任务预测头。

| 模块 | 作用 |
| --- | --- |
| ResNet50 图像分支 | 提取西瓜图片中的叶片形态、颜色、病斑、花果状态、果实大小等视觉特征 |
| Transformer 环境时序分支 | 处理图片拍摄前 24 小时内的空气温度、土壤湿度、光照、pH 时序数据 |
| 特征融合层 | 融合图像特征和环境时序特征 |
| 多任务预测头 | 同时输出生长阶段、健康等级、成熟度等级、异常预警 |

## 7. 标注要求

每张图片和对应环境数据必须标注以下 4 个字段：

```text
生长阶段：
健康等级：
成熟度：
异常预警：
```

标注时必须使用本规格表中的固定标签名称，不能混用其他说法。例如健康等级只能使用“正常、轻微异常、中度异常、严重异常”，不要混用“健康、良好、较差”等未定义词。

## 8. 验收示例

给定一张西瓜图片和对应的 24 小时环境数据后，应能明确填写：

```text
生长阶段：膨大期
健康等级：轻微异常
成熟度：接近成熟
异常预警：有异常
```

如果标注同学无法按上述格式填出 4 个标签，说明标签标准还不够清楚，需要继续细化。
